# NEO

해외 수출 규제 대응 PWA. 해외에 수출하지만 법률·규제 대응팀이 없는 국내 중소기업 담당자를 위한 앱.

법률 변화를 **기업별 영향**과 **실행 항목**으로 변환해, 수출 전 필요한 조치를 확인하고 완료할 수 있게 한다.

핵심 명제: **"이 법이 바뀌었다"가 아니라 "그래서 당신은 이걸 해야 한다"를 판다.**

## 지원 범위 — 도착국 4 × 품목 3

| | 식품·음료 | 화장품 | 전기·전자 |
|---|---|---|---|
| **VN** 베트남 | 법령 4 | 법령 4 | 법령 5 |
| **JP** 일본 | 법령 5 | 법령 5 | 법령 4 |
| **US** 미국 | 법령 5 | 법령 5 | 법령 4 |
| **ID** 인도네시아 | 법령 4 | 법령 4 | 법령 4 |

여기에 국가별 **공용 법령**이 더해진다 — 품목을 가리지 않는 규정(상품 라벨, 강제노동,
원산지 표시, 포장재 재활용, 할랄 등)이다. 화면에는 조합 법령과 공용 법령이 합쳐져 뜬다.

**출발국은 KR 기준으로만 데이터가 있다.** 한미 FTA 원산지증명처럼 출발국을 가리는
요건이 있어서, 다른 출발국을 고르면 그 법령이 목록에서 빠지고 하단에 그 사실을 적는다.

지원하지 않는 도착국(중국·태국 등)도 설정 목록에 흐리게 남긴다 —
"왜 4개국뿐인가"에 정직하게 답하는 장치다.

## ⚠ 데이터 출처 정책 — 실시간 수집이 아니다

**이 앱의 법령 데이터는 사람이 조사해 검증한 정적 데이터셋이다.
법령 데이터베이스를 실시간으로 수집하거나 자동 갱신하지 않는다.**

숨길 이유가 없다. 오히려 이 방식이 더 정확하다 — 자동 수집은 "이 법이 우리 제품의
HS 코드에 걸리는가", "이 날짜가 우리 품목의 날짜인가"를 판정하지 못한다.

조사 규칙은 이렇다.

1. **모르는 건 비운다. 지어내지 않는다.** 이 프로젝트에서 가장 큰 실패는 그럴듯한 값을 채우는 것이다
2. **독립된 출처 2개 이상 교차확인.** 번호·시행일·핵심 변경이 일치해야 기록한다
3. **1차 출처와 2차 출처를 구분해 화면에 표시한다.** 관보·소관 부처 원문이면 `관보` 배지,
   로펌·법률DB·시험인증기관이면 `2차 출처`라고 적는다. 2차를 1차인 척하지 않는다
4. **`최종 확인` 날짜는 그 URL을 실제로 연 날이다.** 임의의 날짜를 넣지 않는다
5. **기한은 법령에 명시된 것만.** 없으면 비운다. 화면 숫자를 맞추려고 역산하지 않는다
6. **그 날짜가 우리 제품의 날짜인지 확인한 뒤에 넣는다.** 법령에 적힌 날짜가
   다른 품목의 유예 종료일인 경우가 실제로 있었다
7. **제외한 법령과 그 사유까지 기록한다**

현재 데이터 — **법령 61건 · 실행 항목 174건 · 1차 출처 47 / 2차 출처 14.**
조사 근거와 판단은 전부 `docs/DATA-SOURCES.md`에 남아 있다. 제외한 법령과 그 사유,
확인하지 못해 비워 둔 값까지 적혀 있다.

`npm run check-data`가 참조무결성과 값 범위를 강제한다.

## 현재 상태

**4차 작업 진행 중.** 6화면과 상태 화면이 동작하고, 12조합 + 공용 4파일에 데이터가 찼다.

| | |
|---|---|
| 화면 | Home / Laws / Law Detail / Company / Map / Notifications / Setup |
| 상태 화면 | 프로필 없음 · 조합 데이터 없음 · 필터 0건 · 스켈레톤 · 에러 · 404 · 오프라인 바 |
| 스택 | Next.js App Router + TypeScript |
| 데이터 | 정적 JSON + localStorage. 백엔드 없음 |
| 지오그래피 | `design/neo-dots.js`를 `d3-geo` + `topojson-client`로 포팅. **CDN 의존 0** |
| PWA | 손으로 쓴 `public/sw.js`. Serwist·next-pwa 쓰지 않는다 |
| 기준 날짜 | `data/meta.json`의 `referenceDate`. 기본값은 `"today"`이고 `new Date()`는 `lib/dday.ts` 한 곳뿐이다 |

런타임 의존성은 `next` · `react` · `react-dom` · `d3-geo` · `topojson-client` 다섯뿐이고
컴포넌트는 전부 직접 썼다. 계획서가 적은 shadcn과 하단 시트용 vaul을 쓰지 않기로 한
경위는 `docs/DISCREPANCIES.md` §14에 있다.

### 오프라인

**설치 후 네트워크가 끊겨도 6화면 + Setup + 법령 상세 61개가 전부 열린다.**

서비스워커가 라우트 문서와 RSC 페이로드에 더해 **그 문서가 참조하는 빌드 청크까지**
프리캐시한다. 빌드 훅이나 매니페스트 없이, 프리캐시한 HTML에서 `/_next/static/*`
참조를 뽑아 담는다.

지도 데이터(`/geo/land-110m.json`)와 폰트·아이콘도 함께 담기므로
**오프라인에서 지도가 그대로 그려진다** — CDN 의존이 0이라는 증거다.

검증 방법: `npm run build && npm start` 로 띄우고 홈을 한 번 연 뒤 서버를 내린다.

## 시작하기

```bash
npm install
npm run dev
```

```bash
npm run check-data     # 법령 데이터 참조무결성
npx tsc --noEmit
npx eslint
npm run build
```

`CLAUDE.md`의 디자인 절대 규칙 9개가 다른 모든 문서보다 우선한다.
그중에서도 `design/NEO-screens.dc.html`이 최종 진실이다 — 문서보다 우선한다.

```
docs/     명세 문서 + 판정 기록(DISCREPANCIES.md) + 조사 근거(DATA-SOURCES.md)
design/   6화면 시각 원본 · 포팅 전 지오그래피 원본 · 아이콘 원본
data/     법령 데이터. <국가>-<품목>.json 12개 + <국가>-shared.json 4개
scripts/  데이터 검사기 · 아이콘 생성기 · 마커 글꼴 생성기
```

## 접근성

- 터치 타겟 **44px** — 6화면 전수 측정으로 확인했다. 시각 크기는 아트보드 그대로 두고
  히트 영역만 넓힌다(`globals.css`의 `.tap` / `.tap-y`)
- 색 대비 — 위험도 색면 위 글자는 전부 AA를 넘는다(최저 5.05:1).
  `--text-3`(3.36:1)은 Meta·라벨에만 쓰고, 본문에 쓰이는 두 곳은 취소선이 함께 걸린
  "지나간 상태"라 색만으로 정보를 전하지 않는다. 자세한 실측은 `docs/DISCREPANCIES.md`에 있다
- `prefers-reduced-motion`에서 스켈레톤 펄스를 끈다
